# 素材协作

局域网 NAS 素材整理 Windows 桌面端，当前版本为 `0.5.0`。各台电脑安装并运行客户端，NAS 仅提供 SMB 文件共享，不需要部署服务器程序。

## 当前能力

- 递归扫描真实素材目录，索引视频、图片和音频；同名文件按所在目录区分。
- 每 50 条记录提交一次索引和待同步事件。可以暂停扫描，重新扫描时保留已有结果，仅提交新增或变化记录；目录仍会重新枚举。
- 本地 SQLite 持久化索引，提供文件名和路径搜索、类型筛选、分页、缩略图与列表视图、素材信息预览、内置播放器、打开文件及复制路径。
- 使用 Pillow 和随安装包提供的 FFmpeg 生成真实图片、视频缩略图。本地缓存按文件路径、大小和修改时间失效，后台处理最多并发 2 个任务，支持批量生成和暂停。
- 每个节点将索引变更写入自己的 NAS 事件目录，其他客户端定期接收。断网保留待发送事件，恢复后重试；重复事件不会重复入库，收到变更时重新检查素材实际状态。
- 任务中心显示扫描、文件索引和缩略图处理的进度及结果。NAS 设置、手动同步、自动同步和安装包更新检查已接入。
- 脚本管理支持正文、审核状态、绑定素材、搜索分页和归档恢复。工单支持要求说明、负责人、截止日期、状态流转与关联素材预览。
- 脚本与工单随 NAS 事件同步，保留每次修改。多人同时编辑保留并行版本，比较后明确合并；陈旧编辑会提示并保留窗口中的草稿。
- 素材卡片和列表支持 Windows 原生文件拖出，传递 NAS 原片路径。可拖入剪映 / Premiere Pro / After Effects 的素材或项目面板；具体接收行为与媒体格式取决于目标软件，尚未完成三个剪辑软件的逐一实机兼容验证。
- 自定义彩色分类，一份素材可属于多个分类；支持未分类筛选、分类数量、本页批量归类、分类归档恢复及多人同步。

文件索引只接受当前素材根目录内的文件，不会复制或移动原始媒体。扫描不自动删除历史记录；文件删除、移动与重命名的完整协作流程尚待实现。

语音转写、画面 OCR、代理视频和剪辑工程交换尚未实现。播放器和原生拖拽组件随安装包提供，在各自电脑运行。权限控制、独占任务认领、自动分配处理任务、日志压缩与共享快照也不包含在当前版本中。

## 素材分类

素材库上方点击“管理分类”，填写名称、选择颜色并保存。分类是素材的逻辑归类，原片保持原位置；当前提供平级自定义分类，不会自动识别视频内容或移动文件建立文件夹。

选中素材后点击“设置分类”；或点击“批量整理”，勾选卡片右上角的方框、列表选择列，使用“全选本页”可选择当前页。然后点击“批量分类”，勾选分类并选择“添加所选分类”或“移除所选分类”。操作只调整勾选的分类，素材已有的其他分类继续保留。翻页和切换筛选会清空批量勾选，防止误处理看不到的素材。

使用“素材分类”下拉框选择某一分类或“未分类”，可以继续按文件名、路径和媒体类型缩小范围。卡片显示彩色标签，鼠标悬停查看完整分类；列表与右侧预览也会显示分类。

分类归档后不再用于筛选和标签显示，原有归类保留；在管理窗口勾选“含已归档”，选择记录、取消“归档此分类”并保存即可恢复。分类改名或归档遇到多人同时编辑时，可查看版本并明确合并。多人归类按添加/移除同步，不会用一个人的整份分类列表覆盖另一个人的列表；未收到的并发新增会保留，需要同步后再移除。

## 脚本与工单

在“设置”填写协作显示名。选中素材后点击“绑定脚本”，可以选择已有脚本或新建；点击“新建工单”会自动关联当前素材。编辑窗口的“关联素材”页签支持搜索全库、添加、移除和直接预览；正文尚未保存时切换到素材预览会保留编辑窗口。

脚本状态为草稿、待审核、已定稿；工单状态为待处理、进行中、待审核、已完成、已取消。负责人是显示名，工单状态不构成权限或排他认领。归档只隐藏记录，勾选“含已归档”后可以恢复。

存在多人并行修改时，列表会显示提醒。打开编辑器的“查看版本 / 处理更新”比较正文和素材绑定，选择一个版本或保留自己的草稿，检查后点击“确认合并保存”。历史版本继续保留。自动同步每 30 秒尝试一次，NAS 离线时可以保存到本机，连接恢复后同步；尚未保存的窗口草稿不会自动同步。

## 预览界面

- 左侧素材库与右侧预览之间可拖动分隔栏，画面随窗口伸缩。窄窗口收起次要详情，保留播放和复制路径操作。
- 双击卡片或列表项在软件内播放；单击预览封面也可播放。勾选“点选即播”后，单击素材即可播放。
- 上一条 / 下一条可连续预览，也会自动跨页。
- 空格暂停/继续，左右键快进退 5 秒，F 或双击播放画面切换全屏，Esc 返回；搜索框输入不触发播放快捷键。
- 进度条和音量使用不同长度与标签，缩略图保持比例，选中素材显示“正在预览”。

## 内置播放器

播放器在每台 Windows 客户端本机运行随包附带的 `mpv.exe`，画面嵌入素材库右侧；进度从播放器读取，支持播放、暂停/继续、停止、拖动定位、音量和全屏，Esc 退出全屏。播放器直接读取素材，不会在 NAS 上启动程序。缩略图继续由随包附带的 FFmpeg 生成。

## 存储和配置

默认目录：

| 用途 | 位置 |
| --- | --- |
| 原始素材 | `\\SmartStorage\新媒体-137964276\素材库` |
| 共享元数据 | `\\SmartStorage\新媒体-137964276\素材协作数据\events\<节点 ID>\` |
| 安装包和更新清单 | `\\SmartStorage\新媒体-137964276\软件库\素材协作` |
| 客户端配置 | `%APPDATA%\素材协作\settings.json` |
| 本地数据库、任务记录和缩略图 | `%LOCALAPPDATA%\素材协作\` |

NAS 保存可在客户端重建索引的不可变事件文件；SQLite 数据库在各自电脑上运行，避免多台电脑通过 SMB 同时写同一个数据库。所有客户端应配置同一素材根目录和协作数据目录，每台电脑保留独立节点 ID。扫描和生成缩略图会读取 NAS 媒体，占用部分网络与磁盘带宽，不能保证与剪辑同时运行时完全没有性能影响。

在 Windows 中先连接 SMB 共享，并通过 Windows 凭据管理器保存访问凭据。密码不写入程序、仓库、日志或更新清单。

## 开发和验证

```powershell
python -m pip install -r requirements.txt
python main.py
python -m unittest discover -s tests -v
```

可以使用 `python main.py --data-dir <独立目录> --no-auto-sync` 隔离本地测试数据与配置。`--smoke-test <输出 JSON 路径>` 会在窗口初始化后记录版本、窗口大小、数据库和 FFmpeg 路径并退出。

## 构建和发布

构建需要 Python 3.13、FFmpeg、mpv 和 Inno Setup 6。`build.ps1` 调用 `tools/build_release.py`，从 `main.py` 读取版本；显式 `-Version` 必须与其一致。构建前安装 PyInstaller 6.22.2、Pillow 12.3.0 和 tkinterdnd2 0.4.3。FFmpeg 默认从 `%LOCALAPPDATA%\Programs\ffmpeg\bin\ffmpeg.exe` 读取，也可设置 `FFMPEG_PATH`。mpv 可通过下面的脚本下载固定版本并验证 SHA-256，也可设置 `MPV_PATH` 指向已有文件。

```powershell
python -m pip install -r requirements.txt PyInstaller==6.22.2
python tools/fetch_mpv.py
.\build.ps1
python tools/run_frozen_smoke.py
```

应用文件生成在 `build\0.5.0\dist\素材协作\`，安装包生成在 `dist\素材协作-0.5.0-setup.exe`。`-Output` 指定安装包输出目录。脚本搜索 PATH 中的 `iscc`、`%LOCALAPPDATA%\InnoSetup\ISCC.exe` 和 Inno Setup 6 的常见目录，也支持 `ISCC_PATH`。安装包是每用户安装，不要求管理员权限；更新保留本地配置、数据库和缓存。中文文件名通过 Python 传递，兼容 Windows PowerShell 5.1。构建中任一命令失败都会返回失败，不再误报构建成功。

冻结版检查使用独立数据目录和裁剪后的 PATH，确认程序可以启动并找到随包组件。可传 `--exe <安装后的素材协作.exe>` 检查实际安装目录。最终用户仅需安装 setup.exe，不需要安装 Python、FFmpeg 或 mpv。

`python tools/verify_installer.py --work-dir D:\CodexBuildCache\nas-media-collaboration` 会对同一个安装包执行隔离试装、逐文件校验、启动、真实播放器、脚本工单和分类操作验证。该工具使用安装器内部验证参数，必须指定全新目录，不创建快捷方式或卸载注册项，不会关闭正在使用的客户端。普通双击安装和软件更新仍按正常安装流程运行。

验证本地安装包后，发布同一个文件，不重新编译：

```powershell
.\build.ps1 -PublishOnly -NasPublishPath "\\SmartStorage\新媒体-137964276\软件库\素材协作" -ReleaseNotes "彩色分类、未分类筛选、本页批量归类及多人同步"
```

发布先暂存安装包并校验 SHA-256，再放入发布目录，最后替换 `manifest.json`。同版本已有不同内容时拒绝覆盖，历史安装包保留。`-PublishOnly` 必须提供发布目录，且本地已存在当前版本安装包；不会运行依赖安装、清理构建目录或编译。省略 `-PublishOnly` 并提供发布目录则会完成构建后直接发布。

客户端检查更新后将安装包复制到本地，验证清单中的 SHA-256，再提示运行安装器。清单与安装包使用 SMB 权限保护，当前尚未加入代码签名和签名验证。
